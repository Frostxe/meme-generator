# 🎭 Генератор мемов

Веб-приложение для создания простых мемов. Пользователь может выбрать фотографию из встроенной библиотеки или загрузить собственное изображение, добавить верхний и нижний текст, изменить размер и цвет текста, а затем скачать готовый мем в формате PNG.

---

## 📌 Возможности

* 🖼️ Загрузка собственной фотографии
* 📚 Встроенная библиотека фотографий
* ✏️ Добавление верхнего текста
* ✏️ Добавление нижнего текста

* 💾 Скачивание готового мема в PNG
* 🔄 Кнопка удаления выбранной фотографии

# 🖼️ Как работает Canvas

Для создания мема используется HTML-элемент:

```html
<canvas id="canvas"></canvas>
```

JavaScript получает доступ к Canvas:

```javascript
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
```

После этого изображение и текст рисуются непосредственно на Canvas.

Сначала программа рисует фотографию:

```javascript
ctx.drawImage(
    img,
    0,
    0,
    canvas.width,
    canvas.height
);
```

После этого поверх фотографии добавляется текст:

```javascript
ctx.strokeText(line, canvas.width / 2, y);
ctx.fillText(line, canvas.width / 2, y);
```

`strokeText()` создаёт обводку текста.

`fillText()` заполняет текст выбранным цветом.

# 📚 Библиотека фотографий

В приложении есть встроенная библиотека изображений.

Каждая фотография представлена кнопкой:

```html
<button class="photo-card" data-image="...">
    <img src="..." alt="Фото">
</button>
```

Когда пользователь нажимает на фотографию, JavaScript получает адрес изображения:

```javascript
const imageUrl = card.dataset.image;
```

После этого создаётся объект `Image`:

```javascript
const image = new Image();
```

И выбранная фотография становится изображением мема.

# 📝 Работа с текстом

Пользователь может ввести:

* верхний текст;
* нижний текст.

Например:

```text
GENERATOR
MEMES
```

Текст автоматически переводится в верхний регистр:

```javascript
text.toUpperCase()
```

Поэтому:

```text
hello world
```

становится:

```text
HELLO WORLD
```

# 🔤 Размер текста

Размер текста управляется ползунком:

```html
<input
    id="size"
    type="range"
    min="4"
    max="16"
    value="9"
>
```

JavaScript рассчитывает размер текста относительно ширины Canvas:

```javascript
const fontSize =
    canvas.width * sizeInput.value / 100;
```

Это позволяет использовать приложение с изображениями разных размеров.

# 🎨 Изменение цветов

Пользователь может выбрать:

### Цвет фона

```html
<input id="bg" type="color">
```

### Цвет текста

```html
<input id="fill" type="color">
```

При изменении цвета функция `render()` вызывается снова, поэтому изменения сразу отображаются на Canvas.

# 📤 Загрузка собственной фотографии

Пользователь может выбрать изображение с компьютера.

Используется:

```javascript
FileReader
```

Файл читается как Data URL:

```javascript
reader.readAsDataURL(file);
```

После загрузки изображение помещается в объект `Image`, а затем отображается на Canvas.

---

# 💾 Скачивание мема

Для скачивания используется:

```javascript
canvas.toDataURL('image/png')
```

Canvas преобразуется в PNG-изображение.

После этого создаётся ссылка:

```javascript
const link = document.createElement('a');
```

И автоматически запускается скачивание:

```javascript
link.click();
```

Файл сохраняется как:

```text
meme.png
```
